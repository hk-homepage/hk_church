# 혜광교회 웹사이트 프로젝트

## 프로젝트 개요

혜광교회 웹사이트는 Next.js 16 (App Router)와 TypeScript를 기반으로 구축된 현대적인 교회 웹사이트입니다.

### 핵심 목표

- **장기적 유지보수성**: 명확한 구조와 예측 가능한 패턴
- **재사용 가능한 컴포넌트**: 코드 중복 최소화
- **일반 사용자 우선**: 관리자 기능은 나중에 추가
- **확장성**: 새로운 기능 추가가 용이한 구조

### 기술 스택

- **프레임워크**: Next.js 16 (App Router)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **UI 컴포넌트**: shadcn/ui
- **데이터베이스**: Supabase (예정)
- **배포**: Vercel

### 프로젝트 철학

1. **명확성 우선**: 복잡하거나 영리한 솔루션보다 명확하고 간단한 솔루션 선호
2. **관심사의 분리**: 라우팅, 컴포넌트, 로직, 스타일을 명확히 분리
3. **타입 안정성**: TypeScript를 통한 컴파일 타임 오류 방지
4. **문서화**: 모든 주요 결정사항과 구조를 문서화

### 주요 기능

#### 현재 구현됨
- ✅ 반응형 레이아웃 (모바일/태블릿/데스크톱)
- ✅ 다크 모드 지원
- ✅ 재사용 가능한 게시판 시스템
- ✅ 페이지네이션
- ✅ 서브 네비게이션

#### 개발 예정
- ⏳ Supabase 데이터베이스 연동
- ⏳ 회원 인증 시스템
- ⏳ 관리자 페이지
- ⏳ 게시글 작성/수정/삭제
- ⏳ 댓글 시스템
- ⏳ 이미지 업로드

### 개발 원칙

#### 코드 스타일
- TypeScript strict 모드 사용
- 함수형 컴포넌트 우선
- Named exports 사용
- 파일명은 kebab-case, 컴포넌트명은 PascalCase

#### 컴포넌트 설계
- 작고 집중된 컴포넌트
- 재사용 가능한 로직은 커스텀 훅으로 추출
- JSX 내부의 복잡한 로직 지양

#### 데이터 처리
- 초기 개발 시 Mock 데이터 사용
- 모든 데이터 모델에 TypeScript 인터페이스 정의
- UI 컴포넌트와 백엔드 구현 간 느슨한 결합

### 시작하기

#### 개발 환경 설정

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 타입 체크
npm run type-check

# 린트
npm run lint
```

#### 환경 변수

`.env.local` 파일을 생성하고 필요한 환경 변수를 설정하세요:

```bash
# Supabase (향후)
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

# Site
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_SITE_NAME=혜광교회
```
