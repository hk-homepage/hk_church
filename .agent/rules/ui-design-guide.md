UI principles:
- UI must be calm, readable, and church-appropriate
- Avoid flashy animations or aggressive colors
- Favor vertical spacing and whitespace
- Mobile-first, then desktop enhancement

Component rules:
- Reusable UI components should live in `components/ui`
- Page-specific UI belongs close to the route
- Board/list/detail layouts should be shared across categories

When designing UI:
- Assume elderly users and mobile users
- Clear typography > visual effects
