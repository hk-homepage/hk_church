This project is a church homepage built with Next.js (App Router) and TypeScript.

Key goals:
- Long-term maintainability
- Clear structure and predictable patterns
- Reusable components over duplicated code
- General users first, admin features added later

The site includes:
- Static pages
- Reusable board-style pages
- Role-based UI differences (user vs admin, admin later)

Always prioritize clarity, simplicity, and extensibility over clever or complex solutions.
